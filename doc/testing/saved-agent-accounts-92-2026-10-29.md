# .92 已保存账号在本地 Agent 页的显示

日期：2026-10-29（America/Los_Angeles）。

## 原因与修改

按需导入已在后端分开两种状态：TokenFlow 已保存的可切换账号，以及外部客户端当前登录是否经过读取。未点击导入时，状态接口会返回 `not-inspected`，同时仍返回 TokenFlow 自有账号的脱敏信息与切换资格。问题出在 Agent 面板以 `hasNativeLogin` 控制整个账号区，导致已经取得的保存账号也被隐藏。

现在已保存账号独立展示，不依赖本机身份读取；读取中或读取失败时也不隐藏已有行。只有实际核对的身份才显示“本机／使用中”，不会从历史授权推断当前客户端登录。全部账号被用户隐藏时保留恢复入口。状态提示区分“已加载保存账号”和“尚未导入”，不再要求有保存账号的用户先导入。

选择已有账号仍使用原有 `POST inspect → revision 校验 → 备份/切换`，不改账号切换、网关路由和凭据存储策略。启动读取自身安全存储的选择保持有效；未选择的外部客户端不进行自动导入。
