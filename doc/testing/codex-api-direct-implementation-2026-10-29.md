# Codex API 直连与模型地址发现

范围：实现 [讨论方案](codex-api-direct-plan-2026-10-29.md)，仅新增 Codex 的客户端直连配置；没有新增 Claude Code 的直连逻辑。API 来源探测本身仍是共享能力。原统一网关的推理、压缩及子代理路由保持现有实现。

## 实现

- 地址候选独立于协议候选：先验证用户输入，再补/去末尾版本段；不移除租户路径、不更换主机、不降级 HTTPS。仅有 Anthropic/Claude 提示时尝试对应子路径。协议与实际端点仍按来源、真实模型 ID 存在 `modelRoutes`，新增验证时间。
- 鉴权、额度、限流、连接失败及上游故障停止地址枚举，避免将这些故障当成路径不匹配。共享取消信号和每模型 30 秒总时限，外层批次仍有总时限。
- `codex-api-capability.ts` 单独验证原生 Responses SSE 完成、真实函数调用及结果回传、多轮续聊和可读摘要。没有完整终态、工具调用或摘要就不发布直连资格。资格按来源＋模型＋端点＋密钥指纹保存七天；变更模型、端点或密钥不能沿用旧结果。响应正文及 Key 不进入资格文件。
- `codex-api-direct.ts` 单独负责直连配置及恢复，使用同一 Codex 配置锁、版本检查、预写日志与原子替换。保留 `auth.json`，写入 API 专属 provider 和原始模型 ID；不创建网关 Key，不调用 TokenFlow 推理端点。直连期间的 Key 位于权限为 0600 的 Codex 配置及私有配置日志中，并不是“只存路径、不存 Key”。
- 配置使用 `remote_compaction=unsupported`，由 Codex 请求当前供应商生成可读摘要；采用 v1 子代理元数据。禁用未经验证的官方托管搜索、图像和推理选项。模型目录使用保守的 32K 调度预算，非声称供应商的实际最大窗口；当前不支持应用到已选择的配置档案。
- 进入统一网关及切换官方账号前，先恢复 API 直连前的配置，包括原认证方式、功能设置及模型目录。无关用户编辑保留，所属字段发生冲突时停止并保留日志。网关恢复和直连切换沿用现有 Codex 生命周期，不接管后台引擎。
- 本地 Agent → Codex 增加“使用 API 直连…”：先验证再应用，验证期间可取消；显示 Chat/Messages 模型需用网关。应用动作明确会重启 Codex；此轮测试没有对生产应用执行此动作。
- 本机记录器识别 `api_direct_<来源ID>`，保留其实际 Token 记录和来源身份，不误认成网关重复记录，也不归到保留的官方登录账号。统计聚合按来源分组。

## 隔离验证

- 9 个相关回归文件 227 项全部通过；并行首次运行有两项真实 sidecar 同步超时，单独重跑及完整串行运行均通过，未放宽检查。
- 最后用量归属和界面调整后，5 文件 57 项通过；自动工具选择修改后，两份直连测试文件 12 项通过。类型检查、生产构建与 diff 空白检查通过。
- 服务集成验证：未验证模型不能应用；API 直连 → 官方账号＋统一网关 → API 直连 → 恢复官方接入。官方登录字节保持一致，网关配置不含供应商 Key 或残留的强制 API 登录字段。
- 原版 `codex-cli 0.166.0-alpha.5.1` 使用产品生成的配置、独立 HOME 与模拟供应商，实际执行 `exec_command` 并校验结果，完成本地压缩、压缩后续聊、进程重启后续聊及配置恢复。全程没有启动 TokenFlow 推理服务。
- CUA 在隔离网页验证入口、选择模型、验证前应用按钮禁用、验证后启用，以及 Chat 模型不能选择直连；检查了弹窗布局。没有点击生产 Codex 的应用或重启。

## DeepSeek 官方实测

用户授权使用已保存的 DeepSeek 官方 API。只读取这一来源的安全存储，Key 经私有 stdin 管道传给隔离测试进程；没有输出凭据，没有读取或发送真实对话，没有更改生产配置、登录、会话或账本。

1. 首次返回 HTTP 402，未启用直连资格。
2. 用户充值后返回 HTTP 400：思考模式不支持探针的强制 `tool_choice`。改为原生常用的 `auto`，仍要求返回真实的工具调用及正确结果；没有关闭思考或降低验证为普通文本问答。
3. 再次实测全部通过：三个协议能力请求成功；原版 Codex 直接请求 `api.deepseek.com` 完成回答、本地压缩、重启恢复及标记核验。未运行 TokenFlow 网关。三个能力请求报告输入 890、输出 118 Tokens；此数不包含随后原版 Codex 的请求，不能作为整个实测的总用量。

结果见 [原版隔离结果](results/codex-api-direct-native-2026-10-29.json) 与 [真实 DeepSeek 结果](results/codex-api-direct-live-2026-10-29.json)。真实测试运行时通过隔离的系统代理解析器访问供应商，这是网络代理，不是 TokenFlow 模型转发。

## 生效范围与限制

此次完成源码和生产构建，未安装新应用、未修改 4180 的 .91 下载包、未重启用户的 Codex 或 TokenFlow。界面入口将在安装包含这次修改的版本后提供。

验证覆盖新会话及供应商自身的可读摘要，不承诺 OpenAI 加密检查点能被第三方读取，也没有将原官方历史强制迁移到 API provider。首次应用提示新开对话测试。供应商 Key、地址变更后需要重新验证并重新应用；已写入 Codex 的凭据不会在 TokenFlow 关闭期间自动跟随安全存储更新。
