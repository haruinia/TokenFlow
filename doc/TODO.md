## 产品设计待确认

### CONFIG-002：配置管理 + 按需协议转换（2026-10-20）

状态：仅记录候选方案，等待用户后续确定方向；确认前不开展实现，也不改变现有接入方式。

目标：兼容时由 TokenFlow 管理客户端配置、备份、切换与恢复，让请求直接发送到来源；需要适配时才经过 TokenFlow。

- **直接接入**：客户端与来源的协议、鉴权方式、模型 ID 均兼容时，写入来源地址、凭据和实际模型 ID，请求链路为「客户端 → 来源」。配置生效后不依赖 TokenFlow 持续运行；来源自身所需服务仍需运行。
- **按需转换**：需要协议转换、模型别名映射或专用账号授权适配时，请求链路为「客户端 → TokenFlow → 来源」。账号授权是否能直连需逐来源确认，不能只按协议名称判断。
- **配置粒度待确认**：直连／转换模式如何选择和展示，以及是否支持按客户端、供应商或模型分别配置；混合接入取决于客户端自身能力。
- **统计边界待确认**：直连请求不经过 TokenFlow 网关，用量依赖可核对的客户端或来源记录；采集不足时明确覆盖范围，不承诺与网关模式相同的统计和控制能力。
- **保留约束**：不自动发送连通性测试；仅在保存时执行约定的验证，或由用户主动点击发送测试。此设计记录本身不触发任何测试请求。

后续由用户确认支持范围、模式选择、配置恢复与统计展示后，再拆分实施任务。当前版本仍采用本机网关接入。
